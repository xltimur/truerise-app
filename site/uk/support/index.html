Часті запитання

Наскільки точна оцінка?

TrueRise надає астрологічну оцінку, а не точну відповідь. Результат залежить від діапазону часу та якості дат подій, які ви ввели.

Чи потрібен точний час народження?

Ні. Можна вказати приблизний діапазон або розширений діапазон, якщо точний час невідомий.

Чи захищені мої дані?

Дані про народження, події, налаштування та результати зберігаються локально на вашому пристрої. У TrueRise немає облікових записів, реклами, аналітики та SDK для відстеження.

Що таке демо-режим?

Демо-режим дозволяє побачити, як виглядає результат, без реального розрахунку. Він працює офлайн.

Чому живий розрахунок потребує з’єднання?

Пошук місця народження та живі розрахунки використовують HTTPS-запити. Розрахунок надсилає необхідні дані стороннєму сервісу для обчислення результату.

Як видалити свої дані?

Скористайтеся налаштуваннями застосунку для видалення локальних даних. Видалення застосунку також видаляє всі локальні дані.
