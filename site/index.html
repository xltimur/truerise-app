How it works

A focused workflow for uncertain birth times.

TrueRise is built around the information people usually have: an approximate time, a birthplace, and the events that shaped their life.

01

Set a time window

Start with an approximate time and width. If the time is unknown, TrueRise can work from a full-day search range.

02

Add life events

Add dated milestones such as moves, relationships, career shifts, health events, or other personal turning points.

03

Review confidence and evidence

The result includes a likely time, a confidence score, and event-by-event evidence so the estimate is inspectable. Candidate times are scored using astrological methods (transits and progressions) and ranked by how well they match your events.

Privacy by default

Demo mode works offline. Your saved data stays on your device.

TrueRise has no accounts, no analytics SDK, no advertising SDK, and no tracking. Demo calculations run fully offline. Live calculations need a connection only when you choose to run one, because the request must be sent over HTTPS to a calculation provider.

  • No login, password, or cloud profile.
  • Birth and event details are stored locally on your device.
  • Settings include a Delete all data action for local app data.
